Arquitetura

Três interfaces, uma API

Loja, PDV e gestão são áreas da mesma aplicação web e falam com uma única API REST. É isso que garante um estoque e uma base de clientes só. Integrações externas ficam isoladas atrás de interfaces.

Camadas por módulo

Cada domínio tem controller, service, DTOs validados com Zod e entidades TypeORM. As regras de negócio ficam nos services.

Integrações desacopladas

Pagamento usa Strategy Pattern (IPaymentGateway), e o frete tem um gerenciador de tokens OAuth2 com renovação automática.

Modelo de dados

Um estoque, dois canais

A decisão central do modelo: cada variante (SKU de cor × tamanho) guarda o saldo qtd_online e o saldo qtd_loja_fisica separados, e toda movimentação vai para stock_log com os valores antes e depois de cada canal. Isso atende ao RNF01 e à auditoria pedida na US23.

Qualidade

Medido a cada push

O SonarCloud analisa os dois repositórios a cada push nas branches main e dev. Um workflow exporta as métricas para a documentação, onde um dashboard e o MeasureSoftGram acompanham a evolução. A linha escura em cada barra marca o piso exigido pelo CI.

Segurança e LGPD

Uma sprint inteira de hardening

Na Sprint 02 de GCES, o time de backend tratou segurança e conformidade como entrega, com diagnóstico e script de evidência para cada item.

Controle de acesso por dono e cargo

Correção de IDOR no cadastro de pessoas: cada um acessa só o que é seu, salvo cargos autorizados.

Rate limiting

Limites de requisição em login, cadastro e checkout contra força bruta e abuso.

Anonimização (LGPD)

Excluir a conta anonimiza os dados pessoais e preserva o histórico de vendas.

Cabeçalhos e configuração

Helmet, validação de CORS_ORIGINS e tamanho mínimo do JWT_SECRET no boot.

Rastreabilidade

Filtro global de exceções com correlation ID (x-request-id) e logs estruturados com Pino.

Cadeia de suprimentos

Auditoria de dependências, GitHub Actions fixadas por SHA e TLS verificável na conexão com o banco.

Entrega contínua

Do commit à loja no ar

Frontend e backend seguem o mesmo pipeline. Nenhum deploy é manual: o CD só roda depois do CI verde na main e termina com um smoke test.
